Build a modern, premium, SEO-optimized website for **Makonde**, a traditional spiritual consultation and guidance practice based in Uganda.

The existing website is:
https://makonde.odoo.com/services

The new website should replace the existing experience with a significantly more professional, trustworthy, mobile-first website designed to generate consultation enquiries through WhatsApp, phone and contact forms.

## 1. TECHNOLOGY

Use:

* Next.js with App Router
* TypeScript
* Tailwind CSS
* Modern reusable React components
* Server Components wherever appropriate
* next/image
* next/font
* Semantic HTML5
* Responsive design
* Accessible UI
* Clean component architecture
* Production-ready code
* No unnecessary dependencies

The project must be easy to deploy to Vercel.

## 2. BRAND POSITIONING

Position Makonde as:

**Traditional Spiritual Guidance & Consultation in Uganda**

The website should communicate:

* professionalism
* confidentiality
* respect
* cultural authenticity
* accessibility
* personal consultation
* clear communication

Do NOT make the website look like a generic occult/spiritual template.

The visual identity should feel African, premium, warm and modern.

Avoid excessive gold, glowing effects, mystical clichés, crystal-ball imagery, fantasy imagery or an overly dark design.

Use a sophisticated natural palette inspired by:

* deep earthy tones
* warm neutrals
* subtle green
* cream/off-white
* restrained accent colors

Use strong typography and generous whitespace.

## 3. IMPORTANT CLAIMS POLICY

Do not make guaranteed or deceptive claims.

Do not state that Makonde can guarantee:

* winning court cases
* winning gambling/betting
* guaranteed financial success
* guaranteed marriage
* guaranteed pregnancy/fertility
* guaranteed visa approval
* guaranteed job offers
* guaranteed political success
* guaranteed healing
* guaranteed removal of supernatural problems

Where appropriate, explain that consultations provide traditional spiritual guidance and that outcomes vary.

Include a clear but non-alarming disclaimer.

## 5. SEO

SEO is a major requirement.

Implement:

* metadata for every page
* unique title tags
* unique meta descriptions
* canonical URLs
* Open Graph metadata
* Twitter/X metadata
* robots.txt
* sitemap.xml
* semantic HTML
* proper H1/H2/H3 hierarchy
* internal linking
* descriptive URLs
* optimized images
* alt text
* breadcrumbs where useful
* JSON-LD structured data

Use Next.js Metadata API.

Create reusable SEO utilities/components.

Use appropriate structured data such as:

* Organization
* LocalBusiness where appropriate
* WebSite
* BreadcrumbList
* FAQPage where the page genuinely contains FAQs

Do not add fake reviews, fake ratings or fake business information to structured data.
